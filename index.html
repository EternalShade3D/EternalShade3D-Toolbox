📦 Installation & Setup Guide

Requirements

  • Blender 4.2+ or later (Full support for Blender 5.2 Extension Manifest)
  • Compatible with Windows, macOS, and Linux

Installation Steps

  1. Download the .zip file after purchase.
  2. In Blender, navigate to Edit → Preferences → Add-ons.
  3. Click the drop-down menu in the top right and choose Install from Disk...
  4. Select your downloaded .zip file and enable Eternal Toolbox ◈.
  5. Press N in the 3D Viewport to open the sidebar.
📐 Dimensions & Truth Mode Guide

Native Blender object.dimensions only reports the raw un-evaluated vertex cage. If you apply a Solidify, Subdivision Surface, or Geometry Nodes modifier, native Blender dimensions remain unchanged.

Truth Mode continuously evaluates the dependency graph (Depsgraph) output, ensuring your numeric readouts match real physical bounding dimensions.

Performance Thresholds & Debouncing: High vertex counts (>100k verts) switch automatically to asynchronous debouncing to keep viewport framerates smooth.
